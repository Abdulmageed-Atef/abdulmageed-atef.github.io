# Abdulmageed Atef MEP Portfolio

Version 3 of Abdulmageed Atef's Mechanical MEP Engineer portfolio, including a professional hero profile photo and improved portfolio presentation.

## Features
- Responsive design
- Editable text directly inside the website
- Add / edit / delete projects
- Saves changes in browser Local Storage
- Sections for About, Expertise, Projects, Experience, Codes, Software and Contact
- No build tools required

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Safari.
3. Click **Edit Mode**.
4. Click highlighted text and edit it.
5. Use **Add Project** to add projects.
6. Click **Save Changes**.

## Important note
This first version saves your edits only in the browser/device using Local Storage.
For a real online admin dashboard that works across devices, the next version should use a backend/database such as Supabase or Firebase.
